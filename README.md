# ScanHub

ScanHub is a simple document scanning application that allows users to scan physical documents into TIFF format,
manage scanned files, and reorder pages using a visual sidebar.
It is designed to keep the workflow clean and focused, with separate admin and user access.

When using the application, make sure to create a database schema using the database_backup.sql file inside config folder.
